# ML Attention Chatbot (RAG)

This is a **Retrieval-Augmented Generation (RAG)** based chatbot built using **Dify**.

## Project Overview
- Built a RAG chatbot using Dify platform (Chatflow)
- Knowledge Base created from a Machine Learning paper on **Attention Mechanisms**
- Used Knowledge Retrieval + LLM to answer questions based on the uploaded PDF
- Answers are grounded in the document (with citations)

## Tech Stack
- Dify (No-code / Low-code platform)
- Knowledge Base (RAG)
- Chatflow
- LLM (GPT-based model)

## Live Demo
[Click here to try the chatbot](https://udify.app/chat/UxKTKnZwD66tmmLY)

## How it works
1. User asks a question
2. Knowledge Retrieval finds the most relevant chunks from the PDF
3. LLM generates the answer using the retrieved context
4. Response is shown with source citation
